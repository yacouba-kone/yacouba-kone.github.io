PROJET PERSONNEL RECENT (disponible yacouba-kone/raspberry_temperature) 
 
Contexte : Ce projet met en oeuvre une chaîne MLOps complète autour d'un capteur Raspberry Pi : réception des mesures 
(température, humidité, intensité lumineuse) depuis Azure Event Hub, nettoyage des données, entraînement d'un modèle de 
régression linéaire qui prédit la température, puis écriture des prédictions dans une base de données (SQL et/ou Duckdb).  
Points clés :  
• L'orchestration des traitements (nettoyage, transformation des données et entrainement du modèle ML) est assurée par 
Kedro,  
• Le suivi des expériences du modèle ML par MLflow, 
• L'industrialisation et le développement/déploiement continue (CI/CD) par Azure DevOps, 
• La gestion des dépendances et des environnements repose sur uv, 
• La visualisation est assurée par Power BI avec une connexion à Duckdb pour la partie Dev et SQL Database pour la 
partie Prod 
• Garantir un workflow coherent et reproductible par des tests unitaires réalisés par pytest,  
• Déployer des services ML sur Azure Kubernetes Services (AKS)  
Environnement technique : Python · Scikit-learn · MLflow · Celery · Kedro · Azure · AKS · Docker/ACR · PostgreSQL · 
Pandas · NumPy · Git
